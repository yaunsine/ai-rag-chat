# 陶瓷制造知识库

本目录是 RAG 问答系统唯一的知识库入口，目录结构、命名和元数据规范见
`docs/knowledge_base_standard.md`。`data_dir` 下的数据库、向量库和索引缓存不再参与文档索引。

## 目录说明

| 目录 | 内容 |
| --- | --- |
| `00_原料与配方/` | 坯体/釉料原料、化学组成、配方设计 |
| `01_生产工艺/` | 从配料到包装的工艺流程、参数基线、烧成曲线 |
| `02_设备与窑炉/` | 主要设备、窑炉结构、点检与维护 |
| `03_质量与检测/` | 检验规范、缺陷原因与对策、抽检要求 |
| `04_标准与规范/` | 产品标准、试验方法、能耗与环保要求 |
| `05_生产管理/` | KPI、批次追溯、现场管理与改善 |
| `06_外部资料/` | 按来源归档的外部采集资料，不与内部工艺文件混放 |

## 使用约定

1. **一个文件只讲一个主题**，主题归属以文件所在目录为准。
2. **内部资料与外部资料分开**：内部工艺文件放 `00`–`05`，采集文章放 `06_外部资料/<来源>/`。
3. **数据表用 UTF-8 CSV**，列名带单位；一行一条记录，避免合并单元格式写法。
4. **外部文章必须保留来源、原文链接和采集日期**，仅用于内部检索测试，不对外转载。
5. 新增或修改文档后，在聊天页点击「更新索引」，或重启服务触发增量索引。

## 检索友好写法

- 每个二级标题下写完整、可独立理解的一段话，避免只写“同上”“见前文”。
- 参数写全“对象 + 数值 + 单位 + 条件”，例如“瓷质砖烧成温度 1180–1230 ℃，周期 45–75 min”。
- 同义词首次出现时并列写出，例如“坯体（生坯）”“釉料（釉浆）”，便于关键词召回。
- 表格适合参数对照；原因分析用“现象 → 原因 → 排查 → 措施”的固定结构。
