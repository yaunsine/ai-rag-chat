## 使用限制

1. 采集内容仅用于**内部知识库检索测试**，版权归中国陶瓷网及原作者所有，不对外转载或商业再分发。
2. 部分文章为企业供稿或展会报道，带有品牌宣传色彩；技术结论应结合企业内部工艺文件复核。
3. 2015–2018 年的设备和工艺文章具有历史参考价值，不代表当前主流水平。
4. 标准类文章可能已被新版本替代，引用标准号前必须核对现行有效文本。
5. 文章中如出现具体企业、产品型号和价格，仅作行业信息，不构成选型或采购建议。

## 更新方法

1. 按站点 `robots.txt` 允许的范围访问公开文章，请求间隔不低于 0.3 秒。
2. 按“来源_标题_文章ID.md”命名，保留 `source_url`、`published`、`collected` 元数据。
3. 新增文章后更新 `_采集清单.csv` 和本文件的目录数量。
4. 删除或下架的文章不要直接覆盖，先查原文链接确认，再在清单中标记。
