# 建筑陶瓷主要生产设备与点检要点

> 适用范围：湿法制粉 + 干压成型 + 辊道窑烧成的建筑陶瓷砖生产线。
> 点检周期为常规建议，企业应按设备说明书、运行工况和历史故障调整。

## 1. 设备清单与工艺位置

| 工序 | 主要设备 | 核心作用 | 关键输出指标 |
| --- | --- | --- | --- |
| 配料 | 皮带秤、螺旋秤、料仓、配料控制系统 | 按配方准确称量 | 配料精度、批次一致性 |
| 制浆 | 球磨机、浆池、搅拌机、除铁器、振动筛 | 粉碎、混合、除铁 | 细度、含水率、比重 |
| 造粒 | 喷雾干燥塔、热风炉、泥浆泵、喷嘴 | 把泥浆制成粉料 | 粉料含水率、颗粒级配、容重 |
| 成型 | 液压压机、模具、布料器、输送线 | 压制成生坯 | 生坯强度、厚度、密度均匀性 |
| 干燥 | 卧式/立式干燥器、热风系统 | 排除生坯水分 | 残余水分、干燥收缩 |
| 施釉 | 淋釉机、喷釉柜、甩釉机、釉浆搅拌桶 | 形成釉层 | 施釉量、釉层厚度 |
| 装饰 | 喷墨机、印花机、喷头清洗系统 | 图案与颜色装饰 | 发色、对位精度、喷印缺陷 |
| 烧成 | 辊道窑、燃烧系统、风机、余热系统 | 烧结与釉料熔融 | 温度曲线、吸水率、色差 |
| 深加工 | 抛光机、磨边机、倒角机、清洗烘干机 | 尺寸与表面精加工 | 尺寸偏差、光泽度、崩边 |
| 分级包装 | 分选线、包装机、码垛机 | 分级、包装、入库 | 等级准确率、包装破损率 |
| 环保 | 除尘器、脱硫脱硝设备、污水处理站 | 达标排放 | 颗粒物、SO₂、NOₓ、废水 |

## 2. 关键设备点检要点

### 2.1 球磨机

- **每班**：检查电流、轴承温度、减速机油位、筒体螺栓、进出料口密封、异常振动和噪声。
- **每周**：检查衬板磨损、球石补充量、筛板堵塞、联轴器同心度。
- **每月**：检查大齿圈润滑、地脚螺栓、电机绝缘；按计划清理磨内结料。
- **常见故障**：细度不达标（球石少/装料过多/时间不足）、筒体漏浆（密封老化）、轴承过热（润滑不足/对中不良）。

### 2.2 喷雾干燥塔

- **每班**：记录进/出塔温度、塔内负压、泥浆压力、粉料含水率；检查喷嘴雾化、塔壁粘料、排料顺畅。
- **每周**：检查喷嘴磨损、泥浆泵密封、热风炉燃烧状态、布袋除尘压差。
- **每月**：清理塔壁和管道积料，校验温度传感器，检查风机轴承和皮带。
- **常见故障**：粉料含水率偏高（进塔温度低/泥浆过稀/产量过大）、粗颗粒（喷嘴磨损/压力不足）、堵塔（粘壁/排料不畅）。

### 2.3 液压压机

- **每班**：检查液压油温、油压、压制压力、模具温度、布料均匀性、生坯外观。
- **每周**：检查液压油位和污染度、滤芯、油缸密封、模具间隙、顶出同步。
- **每月**：校验压力表、检查蓄能器氮气压力、清理油箱呼吸器、检查地脚和减振。
- **常见故障**：中心裂（布料不均/压力过高/脱模过快）、边裂（模具磨损/粉料过干）、粘模（粉料含水高/模具温度低）、厚度波动（粉料容重变化/压制参数漂移）。

### 2.4 干燥器

- **每班**：记录各段温度、湿度、传动速度、出坯残余水分；检查热风管道漏风和辊棒/皮带跑偏。
- **每周**：清理换热器、检查风机轴承、校验温湿度传感器。
- **常见故障**：炸坯（升温过快/入口温度高）、变形（横向温差大）、表面硬壳（前段湿度低）、干燥不足（周期短/温度低）。

### 2.5 喷墨机

- **每班**：检查环境温湿度、墨水液位、负压、喷头状态，打印测试图；清洁喷头表面和编码器。
- **每周**：检查墨路过滤器、管路气泡、喷头清洗液、UV/固化系统（如适用）。
- **常见故障**：断线/缺色（喷头堵塞/墨路气泡）、飞墨（负压异常/喷头脏）、颜色偏差（墨水批次/曲线变化）、堵头（温湿度失控/停机未清洗）。

### 2.6 辊道窑

- **每班**：记录各温区温度、压力、燃气流量、辊棒转速、产品出窑状态；检查火焰、排烟、急冷风量。
- **每周**：校温、检查热电偶、清理辊棒结瘤、检查挡火板和窑体密封。
- **每月**：检查辊棒弯曲和传动、燃烧器、风机轴承、余热换热器；按计划停窑检修。
- **常见故障**：温差大（挡火板/风机/窑体漏风）、断辊（超温/疲劳/卡窑）、辊棒印（结瘤/弯曲/产品过软）、能耗升高（保温损坏/空燃比失调/换热器积灰）。

### 2.7 抛光机与磨边机

- **每班**：检查磨头电流、气压/水压、磨头磨损、传送带跑偏、尺寸和崩边。
- **每周**：检查磨头轴承、同步带、冷却水路、吸尘效果。
- **常见故障**：光泽度不均（磨头压力/磨损不一致）、划痕（磨料杂质/磨头破损）、崩边（磨轮磨损/进给过快）、尺寸超差（导轨磨损/编码器误差）。

## 3. 设备管理建议

1. 建立“一机一档”：设备参数、备件清单、点检记录、维修记录、故障台账。
2. 关键设备（压机、窑炉、喷雾塔、喷墨机）实行状态监测，记录电流、温度、振动趋势。
3. 备件分级管理：易损件（喷嘴、筛网、密封、磨头、辊棒）设安全库存；长周期备件提前采购。
4. 点检发现异常按“发现—记录—派工—维修—验证—关闭”闭环，不遗留带病运行。
5. 每月统计 MTBF（平均无故障时间）和 MTTR（平均修复时间），优先治理高频故障。
