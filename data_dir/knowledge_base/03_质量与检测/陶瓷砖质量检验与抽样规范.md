# 陶瓷砖质量检验与抽样规范

> 适用范围：建筑陶瓷砖从原料进厂到成品出厂的检验与抽样管理。
> 具体抽样方案、判定规则以产品标准、客户合同和企业质量文件为准。

## 1. 检验阶段划分

| 阶段 | 对象 | 目的 | 典型项目 |
| --- | --- | --- | --- |
| IQC 来料检验 | 原料、釉料、墨水、包装材料 | 防止不合格投入 | 化学成分、水分、细度、发色、外观 |
| IPQC 过程检验 | 浆料、粉料、生坯、素坯、釉坯 | 及时发现工序漂移 | 含水率、细度、比重、厚度、强度、施釉量 |
| FQC 成品检验 | 烧成后、抛光磨边后产品 | 判定等级和放行 | 尺寸、表面质量、吸水率、强度、色差 |
| OQC 出货检验 | 包装成品 | 确认批次、标识和运输状态 | 包装、标识、数量、破损、抽样复核 |

## 2. 抽样方法

- 过程检验按班次、球磨号、浆池号、压机号、窑炉曲线号分层抽样；每班至少 3 次。
- 成品检验按批次抽样，批量与样本量可参照 GB/T 2828.1 的计数抽样方案；企业应固定 AQL 水平并写入质量文件。
- 破坏性检验（吸水率、破坏强度、断裂模数、耐磨）按标准规定数量抽取，不能与外观检验样本混用。
- 抽样必须覆盖同一批次的不同位置（窑炉左/中/右、上/下、不同托盘），避免只取外观最好的样品。
- 样品标识包含：品名、规格、色号、等级、生产日期、批次号、抽样人、抽样时间。

## 3. 主要检验项目与方法

| 项目 | 方法/仪器 | 关注点 |
| --- | --- | --- |
| 尺寸偏差 | 游标卡尺、卷尺、尺寸测量仪 | 长、宽、厚；按产品标准允许偏差 |
| 平整度 | 塞尺、平台、平整度仪 | 中心弯曲、边缘弯曲、翘曲 |
| 边直度、直角度 | 直角尺、塞尺 | 边部直线度和相邻边垂直度 |
| 表面质量 | 目视、标准样、光照箱 | 针孔、黑点、裂纹、缺釉、色差、划痕 |
| 吸水率 | 煮沸法/真空法 | 按产品类型判定；瓷质砖 ≤0.5% |
| 破坏强度 | 三点弯曲试验机 | 按规格和厚度换算 |
| 断裂模数 | 三点弯曲试验机 | 反映坯体烧结和强度 |
| 耐磨性 | 耐磨试验机 | 有釉砖分级，无釉砖测磨损体积 |
| 防污性 | 污染剂、清洗 | 有釉砖按标准做易清洗性测试 |
| 光泽度 | 光泽度仪 | 亮光、柔光、哑光分别设定内控范围 |
| 色差 | 色差仪/标准样目视 | 同批、同色号、不同窑位对比 |
| 放射性 | 放射性检测 | 建筑材科 A 类要求 |
| 摩擦系数 | 摩擦系数测试仪 | 地砖防滑要求，按客户/标准 |

## 4. 判定与处置

1. **合格**：全部项目符合标准/合同要求，贴合格标识，按等级入库。
2. **让步接收**：轻微不符合但不影响使用，经技术、质量和客户书面确认后可让步放行，必须单独标识和记录。
3. **返工/返修**：尺寸、崩边、光泽度等可修复项，返工后重新检验。
4. **降级**：外观或尺寸不符合优等品要求但符合合格品要求，按等级降级，禁止混级包装。
5. **报废**：影响安全使用或无法修复的，隔离报废并记录原因。

## 5. 批次追溯

- 批次号建议包含：生产日期 + 生产线 + 班次 + 产品代码 + 流水号。
- 追溯链：成品批次 → 包装记录 → 分级记录 → 窑炉曲线号 → 压机班次 → 粉料仓/浆池 → 球磨号 → 原料批次。
- 客诉处理时先锁定批次，再查同批次留样、过程记录和同窑位产品，判断是个别、批次还是系统问题。
- 留样保存不少于 6 个月；出口或合同有更长要求的按合同执行。

## 6. 质量数据与改善

- 每日统计：成品率、一级品率、缺陷率、客诉数、返工率。
- 每周分析：按缺陷类型、工序、班次、设备、原料批次做帕累托分析，锁定前 3 项。
- 每月复盘：对重复发生的缺陷做原因分析（5Why、鱼骨图），制定纠正和预防措施并验证效果。
- 关键参数纳入 SPC 控制图：粉料含水率、生坯厚度、烧成温度、吸水率、尺寸偏差、光泽度。
- 控制图出现连续 7 点上升/下降、超出控制限或异常波动时，立即停机排查。

## 7. 检验环境与人员

- 外观检验光照条件统一（建议 300–500 lx，色温 5000–6500 K），避免不同班次判定差异。
- 色差判定使用标准光源箱，样品与标准样同角度、同背景对比。
- 检验人员定期培训并做一致性比对（MSA），减少人为判定偏差。
- 仪器按周期校准，保留校准证书和期间核查记录。
